# Yokodori 0.1.1

Status: release preparation. Version 0.1.1 has not been published.

## Installation

After publication, install the auto-discovered Pi package with:

```bash
pi install npm:yokodori@0.1.1
```

For an SDK dependency, use:

```bash
npm install yokodori@0.1.1
```

The package continues to export `yokodori` and `yokodori/pi`. Its Pi manifest points to `./dist/adapters/pi/package-extension.js`; that outer adapter attaches the existing Pi integration in passive `control` mode. Loading it does not inject or rewrite context and does not persist, print, or transmit observed context.

## Pi dependency ownership

`@earendil-works/pi-coding-agent` is an optional peer dependency with the `*` range required by Pi's package guidance. It is not a runtime dependency. Pi's package manager installs npm packages with peer resolution disabled and maps host-provided Pi modules to its own runtime. The exact `1.0.2` Pi package remains a development dependency for typechecking and deterministic integration tests. The package integration was tested against Pi 1.0.2, which requires Node.js 22.19 or newer; Yokodori retains the Node.js `>=22` engine floor from 0.1.0.

## Verification scope

The release candidate is certified from a locally packed npm tarball through Pi's npm package mechanism. Certification checks manifest/entrypoint inclusion, the `yokodori` and `yokodori/pi` imports, Pi discovery/load, absence of a duplicate Pi runtime, and passive provider-context equivalence. This is local verification only; it is not an npm publication, live-provider test, merge, or release.
